# Approval Gates

| Gate | Status | Decision |
|---|---|---|
| HG-1 Requirement sign-off | pending | Requires human confirmation of assumptions and scope. |
| HG-2 Plan and contract approval | pending | Design, task graph, OpenAPI, and risks are prepared. |
| HG-3 Exception gate | not raised | No high-risk exception encountered during generation. |
| HG-4 Release approval | pending | Awaiting validation evidence and human release decision. |

No gate is silently treated as approved.
